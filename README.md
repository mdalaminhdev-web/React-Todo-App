# React To-Do App

A simple and interactive To-Do List application built with React.js.

This project was created as a React learning project to practice components, state management, event handling, forms, and basic CRUD-style task operations.

## ✨ Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ⚡ Interactive React UI
* 🎨 Custom CSS styling
* 🔄 Smooth list animations
* 📱 Simple and beginner-friendly interface
* 🎯 Font Awesome icons

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Font Awesome
* React Flip Move
* Create React App

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mdalaminhdev-web/react-todo-app.git
```

### 2. Go to the project directory

```bash
cd react-todo-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```
